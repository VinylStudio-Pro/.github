## What Is VinylStudio Pro

VinylStudio Pro is a Windows workstation for people who still play records they own and want digital copies of those sides. It is not a generic DAW. The path is: cue the LP, record both sides with VinylStudio Pro vinyl recorder, let VinylStudio Pro track split propose songs, confirm VinylStudio Pro album metadata, then export. VinylStudio Pro LP transfer is that whole path in one seat.

Collectors look this up because Audacity-style editors do not think in albums. A two-sided record, a 45 with a lock groove, a boxed set with inner sleeves - those are album problems. Metadata lookup is for discs in your crate, not for assembling a library of albums you never bought.

VinylStudio Pro is not a store and not a ripper for other people's vinyl. Record from a turntable and preamp you administer. Keep the files with the records you own. If a side is too damaged, the program will not invent a clean master; it will only help you store a honest transfer.

## Starting with VinylStudio Pro

Prerequisites: A PC you administer, a turntable and preamp you already run, and LPs you own.

1. **Prepare:** Clean the stylus and the first disc, then confirm the sound card input hears the preamp.
2. **Configure:** Set VinylStudio Pro vinyl recorder to the sample rate you keep for archives, and pick a folder for this crate.
3. **Test:** Record one short side, run VinylStudio Pro track split, and check that gaps land near real song breaks.
4. **Refine:** Nudge markers, confirm VinylStudio Pro album metadata against the jacket in your hand, and set export naming.
5. **Apply:** Work through the crate. Use VinylStudio Pro LP transfer the same way on every disc you decide to copy.
6. **Maintain:** Back up exported folders with the records they came from, and recapture a side only if the first take was flawed.
